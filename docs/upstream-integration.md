先完整转写、解析内容，默认末次完整重录，优先级仍为“逻辑完整 → 个人表达 → 节奏紧凑”。24 张源帧选底图、6 张正式封面选成图、粗剪与倍率确认、视觉编排包确认不变。五平台各五条标题、两张工作表与本次成片哈希绑定，归档到主题 `output/`。

完整截图、最小遮罩、同组证据逐项展开、viewer-first 摆放、素材镜像、流式大文件哈希和帧精度修复保留。生成器与合成入口不能绕过视觉批准和 A-roll 锁；待审改稿不能沿用旧包批准。

新任务使用 [统一规划入口](workflow.md#unified-planning-for-new-jobs)。旧任务没有新输入/快照时继续原入口，只在真实返工时迁移受影响部分。波形 tightening 支持单源、单轨、连续、整数 fps、1x；windows 支持真实倍率。批量编辑后用实际回读刷新映射，不把 proposed 当作已执行结果。

新缓存合约可能使旧片段失效；补关键词也可能改变输入指纹，不承诺全部旧缓存命中。已有成片的修订先写 candidate，再验证媒体和标题。静帧帮助检查排版；编码窗口证明真正入场与退出。
